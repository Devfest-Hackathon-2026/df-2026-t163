# 写真の置き場所

各駅の写真を **`{駅ID}.jpg`**（.png / .webp も可）の名前でこのフォルダに置いてください。

- 自分たちで撮った写真か、使ってよいと決まっている写真だけを使う（このフォルダは Git に上げない設定です）
- 駅舎や名所が画面いっぱいに写っていて、看板や人が少ない写真ほどきれいな線画になります
- 1枚だけ作るなら: `python tools/make_stamp_art.py --project プロジェクトID --only {駅ID}`
